== Current Focus

I spend most of my time at the intersection of AI engineering and developer advocacy -- specifically how coding agents are changing the way software gets built. I delivered a talk on this at https://devnexus.com[DevNexus 2026]: *"Unlocking Engineering Productivity with IDE-Based Coding Agents"*, covering production-grade agent orchestration, skill discovery, and what it actually looks like to build with agents at scale inside a large organization.

== Current Project

https://github.com/joshkurz/joshkurzsite[joshkurzsite] is a dad joke site built entirely with Claude Code -- and a living example of how to build better with AI. The project doubles as a practical exploration of coding agent workflows, from initial scaffolding to iterative feature development. If you want to see what AI-assisted development looks like in practice, this is it.
